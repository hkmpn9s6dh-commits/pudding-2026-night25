# 闸 D：第一眼

## 为什么这样设

The Pudding Cup 没有往届得奖作品可供比对（2025 才办第一届，得奖作是单篇网页，形态与本作同源）。
所以尺子换成**同一出版方 2026 年发表的三篇**：R1 词频、R2 Kevin Bacon、R3 IVF。
这对本作是**更苛刻**的尺子——同一家刊物自己的水准线。

## 材料

- 尺子：R1/R2/R3（The Pudding，2026 年三篇，1440×900 首屏截图）
- 参赛：S1–S7（本作分屏截图，S7 为 390px 手机版）
- 评委：**家用 Win 上的 GLM-5.3F** 与 **Kimi-K3.1-Pro**（不同家族，互不通气）

### 两人各自点到的问题（原文见 AME-1482 / AME-1483）

1. **两人都点到**：格子图三种状态分不开 —— 深蓝（整夏 0 夜）与"没有记录"在缩略尺度上读起来都是灰。**必须改**。
2. **Kimi 点到（真错）**：标题写 "fifty years apart"，1976→2024 是 **48 年**。**必须改**。
3. **Kimi 点到**：正文"心率下不来 / 深睡变浅"两句旁边没有出处（出处都在页脚）。**改了：加编号上标，就近指向页脚五条来源。**
4. **GLM 点到**：首屏副题说 22 城、数据行说 30 城，中间缺口要到第二节才补。**改了：`30 attempted · 22 usable`。**
5. **GLM 点到（真 bug）**：缺测名单没有按可用夏天数排序（Lahore 25、Jakarta 20 排在 0 后面）。**改了：按 usable 降序。**
