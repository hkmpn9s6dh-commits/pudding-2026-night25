# 闸 D：第一眼

## 为什么这样设

The Pudding Cup 没有往届得奖作品可供比对（2025 才办第一届，得奖作是单篇网页，形态与本作同源）。
所以尺子换成**同一出版方 2026 年发表的三篇**：R1 词频、R2 Kevin Bacon、R3 IVF。
这对本作是**更苛刻**的尺子——同一家刊物自己的水准线。

## 材料

- 尺子：R1/R2/R3（The Pudding，2026 年三篇，1440×900 首屏截图）
- 参赛：S1–S7（本作分屏截图，S7 为 390px 手机版）
- 评委：**家用 Win 上的 GLM-5.3F** 与 **Kimi-K3.1-Pro**（不同家族，互不通气）

### 两人各自点到的问题（原文见 AME-1482 / AME-1483）

1. **两人都点到**：格子图三种状态分不开 —— 深蓝（整夏 0 夜）与"没有记录"在缩略尺度上读起来都是灰。**必须改**。
2. **Kimi 点到（真错）**：标题写 "fifty years apart"，1976→2024 是 **48 年**。**必须改**。
3. **Kimi 点到**：正文"心率下不来 / 深睡变浅"两句旁边没有出处（出处都在页脚）。**改了：加编号上标，就近指向页脚五条来源。**
4. **GLM 点到**：首屏副题说 22 城、数据行说 30 城，中间缺口要到第二节才补。**改了：`30 attempted · 22 usable`。**
5. **GLM 点到（真 bug）**：缺测名单没有按可用夏天数排序（Lahore 25、Jakarta 20 排在 0 后面）。**改了：按 usable 降序。**

两人二轮点到的新问题（都是"说法"层，不是数据层）：

1. **共同**：引注上标在截图里太小，看不出"这句有出处" → 上标字号 .62em → **.78em + 加粗 + 红**。
2. **共同**：图例只有 0–92 渐变，缺"无记录"样例 → **加一个描边的浅色样例 + "no record"**。
3. GLM：S5 里广州 −11、里约 −7、孟买 −3 三个逆势数字全文没有解释 → **加一句"记录完整，这不是数据缺口；我拿不出机制，宁可这么写也不编"**。
4. GLM：S3 副文没定义"summer" → **补口径（1991–2020 月均 Tmin 最高三个月；南半球 12–2 月，记在次年）**。
5. Kimi：S6 "热夜早已是常态的地方"是对八城的概括，无逐城出处 → **改成可验的说法："八座全在热带或亚热带"**（|lat| ≤ 32°，点开仓库就能核）。

第三版改完**没有再送审**（两轮就停）。所以闸 D 的结论如下。

## 结论

**条件性通过。**

- 两轮里，**两位评委各两次、共四次排名，S 两次第 2、一次第 4、一次第 2**（第 4 是首轮 Kimi）。
- 二轮两人都把 S 排在 4 件里的**第 2**，仅次于 R3（同一出版方 2026 年的成熟作品）。
- **一人判进、一人判不进**；不进的那一位两轮都没改口，理由是证据链完成度。
- 按预登记判据（两人都进才叫过线），记**条件性**；不按"平均一下就算过"。

## 这一闸真正值钱的地方

两位评委独立点到了**同一处**（缺测与 0 夜分不开）与**同一类**（说法没有就近支撑），
并且抓到一个**真错**（1976→2024 不是 50 年，是 48 年）。这三件都不是数据错，是**表达错**，
而它们恰好是自审最难发现的：我知道自己想说什么，所以读不出来。
