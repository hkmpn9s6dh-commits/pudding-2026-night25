# 方法

## 1. 城市框架

UN DESA《World Urbanization Prospects 2018》城市集聚区人口前 30 名。**不按数据可得性挑选**——
先定城市，再去找温度计。这样做的好处是"哪几座测不到"本身成了结论。

## 2. 选站规则（先定规则，再看结果）

对每座城市：

1. 在 NOAA `isd-history.csv` 里取距市中心 **45 km** 以内的站点；
2. 要求 1975 年前开始、2023 年后仍在报；
3. 取其中最近的机场站（GSOD 的观测主体）；
4. 用该站的逐日 `MIN`（华氏，转摄氏）算夏季，**有 ≥35 个夏天满足 90% 天数**才进主图。

站点变更、迁址、城市热岛都会污染"城市温度"这个概念；用机场站是为了**同一条记录贯穿 50 年**，
代价是它代表的是机场而不是市中心。

## 3. 夏季与阈值

- 夏季 = 1991–2020 基准期里，月均 TMIN 最高的连续三个月（跨年允许）。南半球因此落到 12–2 月。
- 热夜 = 夏季里 `TMIN ≥ 25.0 °C`。
  WMO 的"热带夜"国际通用阈值是 **20 °C**；中国长三角（沪宁杭）气象部门按本地湿热气候采用 **25 °C**。
  本项目取 25 °C，因为要回答的是"能不能睡"，不是"会不会结霜"。
- 某年有效天数 < 90% → 该年记 `null`，**不插值**。这一条会直接吃掉早期年份，页面上的空洞就是它。

## 4. 趋势与均值

- "那时" = 1976–1995 平均，"现在" = 2005–2024 平均（各 20 年，避免单年噪声）。
- 趋势 = 对有效年做最小二乘，输出 °C/decade（或 夜/decade）；有效年 < 35 不出趋势。
- 未做去趋势、未做城市热岛订正、未做同质性检验（GHCN 的逐日产品本身不带这些）。

## 5. 已知弱点（写在页面上，不藏）

1. **机场站不是城市**：热岛强度、绿地、楼高都不同。
2. **昼 vs 夜的比较是"这两个指标"的比较**，不是辐射强迫的归因。
3. **8 座城市完全缺失**，且系统性地偏热、偏穷、偏快速增长 —— 结论不能外推到"全球城市"。
4. **2024 之后没有**：数据集到 2024 年为止。
5. **单站代表全城**：墨西哥城、雅加达这类多站城市被单站替代，误差未量化。
