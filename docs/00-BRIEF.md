# 赛事简报：The Pudding Cup 2026

- 官方：https://pudding.cool/pudding-cup/
- 主办：The Pudding（美国，数据新闻刊物）
- 截止：**2026-11-30（周一，美东）**；获奖公布 12-07 当周
- 奖金：最多 3 名，各 **$1,500**
- 参赛成本：**免费**
- 提交方式：一个 URL（Google Form），**一人一件**

## 原文条件（逐条）

## 对本项目的约束

1. **必须公开在公网**（GitHub Pages 即可），且是本年度发布。
2. **不能带商业推广**、不能挂付费墙、不能是接活做的。
3. **要交过程**：仓库、站点清单、每月 URL 与 sha256、抽取数据全部随包。
4. **AI 披露**：主办方明确对"AI 疲劳"有情绪，页面里直说 AI 参与了什么、判断是人的。
5. 一人一件：这件就是唯一一件，不再投第二件。

## 不做什么

- 不做通用"全球变暖很可怕"图表；每个数字必须能回溯到一行观测。
- 不用任何需要登录/付费的数据源。
- 不代用户填 Google Form。
